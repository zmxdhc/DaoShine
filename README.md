# DaoShine

DaoShine facilitates scalable, distributed data processing with auto-scaling and predictive-analytics capabilities via a robust module library.

DaoShine is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/DaoShine.git`
2. `cd DaoShine`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure DaoShine, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
